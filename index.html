Flexbox Lesson

Learn the fundamentals of CSS Flexbox layout

1. Basic Flexbox Container

Use display: flex to create a flex container. All direct children become flex items.

display: flex

This property makes an element a flex container. The element becomes a block-level flex container box.

display: flex;
Item 1
Item 2
Item 3
HTML Code 
<div class="container">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
CSS Code 
.container {
  display: flex;
  /* Items will flow horizontally by default */
}

2. Flex Direction

Control the direction of flex items with flex-direction

flex-direction

Sets the direction of the main axis. Determines how flex items are placed in the flex container.

6. Flex Item Properties

Control individual flex items with flex-grow, flex-shrink, and flex-basis

flex-grow, flex-shrink, flex-basis

These properties control how flex items grow, shrink, and their initial size. Often used together as the shorthand flex.

flex: [grow] [shrink] [basis]; /* Shorthand */ flex-grow: [number]; /* Default: 0 */ flex-shrink: [number]; /* Default: 1 */ flex-basis: [size]; /* Default: auto */

Flex Grow

Normal
Grow 2x
Normal
HTML Code 
<div class="flex-grow-demo">
  <div>Normal</div>
  <div class="grow-2">Grow 2x</div>
  <div>Normal</div>
</div>
CSS Code 
.grow-2 {
  flex-grow: 2; /* Takes 2x more space than others */
}

/* Other items have flex-grow: 0 (default) */

Flex Shrink

Normal
No Shrink

7. Real World Example: Navigation Bar

Here's how Flexbox is commonly used in navigation bars

Practical Application

Navigation bars are a perfect use case for Flexbox. They need to be responsive, align items properly, and handle different screen sizes.

/* Common navigation patterns */ .navbar { display: flex; justify-content: space-between; } .nav-menu { display: flex; gap: 2rem; } .nav-actions { display: flex; gap: 1rem; }
Logo
  • Home
  • About
  • Services
  • Contact
HTML Code 
<nav class="navbar">
  <div class="nav-brand">Logo</div>
  <ul class="nav-menu">
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
    <li><a href="#">Services</a></li>
    <li><a href="#">Contact</a></li>
  </ul>
  <div class="nav-actions">
    <button class="btn">Login</button>
    <button class="btn btn-primary">Sign Up</button>
  </div>
</nav>
CSS Code 
.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 1rem 2rem;
}

.nav-menu {
  display: flex;
  list-style: none;
  gap: 2rem;
}

.nav-actions {
  display: flex;
  gap: 1rem;
}
